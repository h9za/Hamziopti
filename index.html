Download and open it in 4 steps

No installation. It is a folder you unzip and run.

Download the ZIPPress the download button below and accept the save prompt. The file is called Hamziopti.zip.
⬇ Download Hamziopti.zip
Unzip the whole folderRight-click the ZIP, choose Extract All, then open the new folder. Keep all the files together. Do not run it from inside the ZIP.
Open the appRight-click Start-Hamziopti.bat and choose Run as administrator. Admin rights are needed for the power plan, Overclock Lab and FPS Lab. Want a real app window with no browser frame? Install Node.js once, then run Run-As-App.bat instead.
If Windows warns youSmartScreen may say "unknown publisher" because the script is not signed. Click More info, then Run anyway. The scripts are plain text, so you can open them in Notepad first.
For FPS Lab: download Intel's free PresentMon console exe from its GitHub releases and put it in the same folder as Hamziopti.ps1 (do not rename it). It measures frames without touching your game.

Hard limits

It never touches antivirus, firewall, UAC or voltages. GPU tuning stops at +10% of stock and at safe temperatures.

No guarantees

Any overclocking can cause instability or hardware damage, and no software can promise a rollback after a crash. Gains are usually small.

Questions

Is it a virus?

No. It is a PowerShell script and a web interface, and every line is readable in Notepad. Windows warns because it is unsigned, not because it is malicious. Only run software you are comfortable inspecting.

Will it raise my FPS?

Maybe a little. Windows is already well tuned, so removing heavy startup programs and freeing disk space often help most. FPS Lab lets you measure before and after instead of guessing.

Does it work on AMD or Intel graphics?

The tweaks, startup tools and FPS Lab work on any PC. GPU overclocking is NVIDIA only.

Nothing opens. What now?

Look for Hamziopti-error.log next to the script and send its text to whoever gave you the app.
